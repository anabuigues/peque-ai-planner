# Peque AI Planner

Aplicación para descubrir y encontrar planes con niños cerca de ti.

## Qué es

Peque AI Planner es una herramienta que ayuda a familias a encontrar actividades y planes adaptados a niños. Usando inteligencia artificial, sugiere opciones según la edad de los peques, la ubicación, el tiempo disponible y las preferencias de cada familia.

## Para qué sirve

- Buscar actividades y planes para hacer con niños
- Filtrar por edad, duración, distancia o tipo de actividad
- Obtener recomendaciones personalizadas con IA
- Descubrir planes nuevos en tu ciudad o cuando viajas
